# Konfigurations- und Account-Verwaltungs-UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two new frontend pages — "Konfiguration" (edit every wallet address/API key currently in `.env`, saved changes take effect on the next sync with no server restart) and "Accounts" (list every account in the DB and delete specific ones on demand, independent of `.env`).

**Architecture:** A new `app/env_file.py` module owns reading/writing the `.env` file directly (not via `os.environ`) plus the single source of truth for which fields the UI exposes. `app/config.py` gets a `reload_config()` function that re-runs `load_dotenv(..., override=True)` and refreshes its existing module-level constants in place — `app/adapters/factory.py` already reads them via live `config.<NAME>` attribute access, so this alone makes "next sync uses new config" work with zero changes to `factory.py`. `app/prune.py` gains a generic `delete_accounts()` primitive and a `list_accounts()` query, with the existing `prune_stale_accounts()` refactored to use the former (identical external behavior). Four new endpoints (`GET/POST /api/config`, `GET /api/accounts`, `POST /api/accounts/delete`) expose all of this; two new React pages consume them.

**Tech Stack:** Same as the rest of this project (Python/FastAPI/SQLAlchemy/pytest backend, React/TypeScript/Vite/Tailwind/Vitest frontend). No new dependencies.

**Related docs:**
- [`docs/superpowers/specs/2026-08-10-config-ui-design.md`](../specs/2026-08-10-config-ui-design.md)

**Design decisions (confirmed with user):**
- Secrets (Kraken/Coinbase/MEXC/Binance API secrets, Coinbase private key) are **never** sent to the frontend — `GET /api/config` always returns `""` for them. An empty secret value on save means "leave unchanged"; an empty value on any other (visible) field means "clear it".
- Structured form (one input per `.env` variable, grouped by chain/exchange), not a raw `.env` textarea.
- The Accounts page lists **every** account (not just unconfigured ones) with a checkbox per row and a "delete selected" action — independent of `/api/prune`'s existing "delete only what's no longer configured" behavior, which stays as-is.
- `DATABASE_URL` is intentionally excluded from the UI (only takes effect at process start via the SQLAlchemy engine; reloading it here would silently do nothing).
- No authentication added — matches this single-user, local-only tool's existing trust model (README already documents no-auth-by-design).

```python
from dataclasses import dataclass

    ConfigField("MEXC_API_SECRET", "MEXC", "API-Secret", True, ""),

    ConfigField("BINANCE_API_KEY", "Binance", "API-Key", False, ""),
    ConfigField("BINANCE_API_SECRET", "Binance", "API-Secret", True, ""),
    ConfigField("BINANCE_TRADING_PAIRS", "Binance", "Trading-Paare", False, "SYMBOL:BASE:QUOTE, kommagetrennt"),
    ConfigField("BINANCE_SYNC_START", "Binance", "Sync-Start-Datum", False, "YYYY-MM-DD"),
]

_SECRET_FIELD_NAMES = {f.name for f in CONFIG_FIELDS if f.is_secret}


def _read_raw_values(path: str) -> dict[str, str]:
    try:
        with open(path, "r", encoding="utf-8") as f:
            lines = f.readlines()
    except FileNotFoundError:
        return {}

    values: dict[str, str] = {}
    for line in lines:
        stripped = line.strip()
        if not stripped or stripped.startswith("#") or "=" not in stripped:
            continue
        key, _, value = stripped.partition("=")
        values[key.strip()] = value.strip()
    return values


def read_config_values(path: str = ENV_FILE_PATH) -> dict[str, str]:
    """Current value per known field, read directly from the .env file
    (not os.environ -- this must reflect the file even before the running
    process has reloaded). Secret fields are always "" regardless of what
    is actually stored: the real value never reaches the frontend."""
    raw = _read_raw_values(path)
    return {
        field.name: ("" if field.is_secret else raw.get(field.name, ""))
        for field in CONFIG_FIELDS
    }


def write_config_values(updates: dict[str, str], path: str = ENV_FILE_PATH) -> None:
    """Apply `updates` (field name -> new value) to the .env file in
    place, preserving every other line (comments, unrelated variables)
    untouched.

    A SECRET field's empty string means "leave the existing stored value
    unchanged" (the UI never shows secrets, so an empty submission isn't
    a deliberate clear). Every other field's empty string is a deliberate
    clear -- the UI does show the current value, so the user seeing and
    blanking it is intentional.
    """
    effective_updates = {
        name: value
        for name, value in updates.items()
        if not (name in _SECRET_FIELD_NAMES and value == "")
    }
    if not effective_updates:
        return

    try:
        with open(path, "r", encoding="utf-8") as f:
            lines = f.readlines()
    except FileNotFoundError:
        lines = []

    seen: set[str] = set()
    new_lines: list[str] = []
    for line in lines:
        stripped = line.strip()
        if stripped and not stripped.startswith("#") and "=" in stripped:
            key = stripped.partition("=")[0].strip()
            if key in effective_updates:
                new_lines.append(f"{key}={effective_updates[key]}\n")
                seen.add(key)
                continue
        new_lines.append(line)

    remaining = [name for name in effective_updates if name not in seen]
    if remaining:
        if new_lines and not new_lines[-1].endswith("\n"):
            new_lines[-1] += "\n"
        for name in remaining:
            new_lines.append(f"{name}={effective_updates[name]}\n")

    with open(path, "w", encoding="utf-8") as f:
        f.writelines(new_lines)
```

```python
from dataclasses import dataclass
from datetime import datetime, timezone
import os

from dotenv import load_dotenv

from app.env_file import ENV_FILE_PATH

load_dotenv(ENV_FILE_PATH)


@dataclass(frozen=True)
class WalletConfig:
    label: str
    address: str


@dataclass(frozen=True)
class TradingPairConfig:
    symbol: str
    base_asset: str
    quote_asset: str


def parse_wallets(env_value: str | None) -> list[WalletConfig]:
    if not env_value:
        return []
    wallets = []
    for entry in env_value.split(","):
        label, _, address = entry.partition(":")
        label = label.strip()
        address = address.strip()
        if address:
            wallets.append(WalletConfig(label=label, address=address))
    return wallets


def parse_trading_pairs(env_value: str | None) -> list[TradingPairConfig]:
    if not env_value:
        return []
    pairs = []
    for entry in env_value.split(","):
        parts = entry.split(":")
        if len(parts) != 3:
            continue
        symbol, base_asset, quote_asset = (p.strip() for p in parts)
        if symbol and base_asset and quote_asset:
            pairs.append(TradingPairConfig(symbol=symbol, base_asset=base_asset, quote_asset=quote_asset))
    return pairs


def parse_sync_start(env_value: str | None) -> datetime | None:
    """Parse an optional 'YYYY-MM-DD' date string (e.g. Binance account
    creation date) into a UTC midnight datetime. Returns None if unset or
    malformed, in which case the caller falls back to its own default."""
    if not env_value:
        return None
    try:
        return datetime.strptime(env_value.strip(), "%Y-%m-%d").replace(tzinfo=timezone.utc)
    except ValueError:
        return None


def normalize_pem_env_value(env_value: str | None) -> str:
    """PEM private keys are multi-line; when stored in a .env file they're
    typically written with literal backslash-n sequences instead of real
    newlines. Convert those back to real newlines so the value is usable
    directly as a PEM string."""
    if not env_value:
        return ""
    return env_value.replace("\\n", "\n")


def _load_all_from_env() -> None:
    """Assign every hot-reloadable config constant from the current
    os.environ. Called once at import time below, and again by
    reload_config() after re-reading the .env file -- reassigning these
    module-level names is what makes every existing `config.<NAME>`
    attribute access (e.g. app.adapters.factory) see fresh values on its
    very next read, with no process restart."""
    global BITCOIN_WALLETS, BITCOIN_XPUBS, ETHEREUM_WALLETS, ETHERSCAN_API_KEY
    global SOLANA_WALLETS, CARDANO_WALLETS, CARDANO_STAKE_WALLETS, VECHAIN_WALLETS
    global KRAKEN_API_KEY, KRAKEN_API_SECRET
    global COINBASE_API_KEY_NAME, COINBASE_API_PRIVATE_KEY
    global MEXC_API_KEY, MEXC_API_SECRET, MEXC_TRADING_PAIRS
    global BINANCE_API_KEY, BINANCE_API_SECRET, BINANCE_TRADING_PAIRS, BINANCE_SYNC_START

    BITCOIN_WALLETS = parse_wallets(os.getenv("BITCOIN_ADDRESSES"))
    BITCOIN_XPUBS = parse_wallets(os.getenv("BITCOIN_XPUBS"))
    ETHEREUM_WALLETS = parse_wallets(os.getenv("ETHEREUM_ADDRESSES"))
    ETHERSCAN_API_KEY = os.getenv("ETHERSCAN_API_KEY", "")
    SOLANA_WALLETS = parse_wallets(os.getenv("SOLANA_ADDRESSES"))
    CARDANO_WALLETS = parse_wallets(os.getenv("CARDANO_ADDRESSES"))
    CARDANO_STAKE_WALLETS = parse_wallets(os.getenv("CARDANO_STAKE_ADDRESSES"))
    VECHAIN_WALLETS = parse_wallets(os.getenv("VECHAIN_ADDRESSES"))
    KRAKEN_API_KEY = os.getenv("KRAKEN_API_KEY", "")
    KRAKEN_API_SECRET = os.getenv("KRAKEN_API_SECRET", "")
    COINBASE_API_KEY_NAME = os.getenv("COINBASE_API_KEY_NAME", "")
    COINBASE_API_PRIVATE_KEY = normalize_pem_env_value(os.getenv("COINBASE_API_PRIVATE_KEY"))
    MEXC_API_KEY = os.getenv("MEXC_API_KEY", "")
    MEXC_API_SECRET = os.getenv("MEXC_API_SECRET", "")
    MEXC_TRADING_PAIRS = parse_trading_pairs(os.getenv("MEXC_TRADING_PAIRS"))
    BINANCE_API_KEY = os.getenv("BINANCE_API_KEY", "")
    BINANCE_API_SECRET = os.getenv("BINANCE_API_SECRET", "")
    BINANCE_TRADING_PAIRS = parse_trading_pairs(os.getenv("BINANCE_TRADING_PAIRS"))
    BINANCE_SYNC_START = parse_sync_start(os.getenv("BINANCE_SYNC_START"))


_load_all_from_env()

DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./krypto_dashboard.db")


def reload_config(path: str | None = None) -> None:
    """Re-read the .env file and refresh every hot-reloadable config value
    in place. `override=True` is required: python-dotenv's load_dotenv()
    otherwise only sets environment variables that aren't already present
    in os.environ, silently ignoring a changed value for one that's
    already loaded (which every value here already is, from the initial
    load_dotenv() call above at import time).

    DATABASE_URL is deliberately not touched here -- see its comment
    above; reloading it would silently do nothing since the SQLAlchemy
    engine is already built from whatever it was at process start.
    """
    load_dotenv(path or ENV_FILE_PATH, override=True)
    _load_all_from_env()
```

```python
from sqlalchemy import delete, func, select
from sqlalchemy.orm import Session

from app.adapters.base import TransactionAdapter
from app.models import SyncState, Transaction


def list_accounts(session: Session, adapters: list[TransactionAdapter] | None = None) -> list[dict]:
    """Every distinct (source_name, account_label) pair with any data in
    the DB -- from Transaction rows AND SyncState rows (a sync that always
    errors before writing any transaction still has a SyncState row, and
    should still show up here so it can be cleaned up).

    `is_configured` is purely informational (whether the pair is among the
    given `adapters`, e.g. built fresh from the current .env) -- it does
    NOT gate deletion; see delete_accounts.
    """
    configured = {(a.source_name, a.account_label) for a in adapters} if adapters is not None else set()

    tx_rows = session.execute(
        select(Transaction.source_name, Transaction.account_label, func.count(Transaction.id))
        .group_by(Transaction.source_name, Transaction.account_label)
    ).all()
    tx_counts = {(row[0], row[1]): row[2] for row in tx_rows}

    sync_by_account = {
        (s.source_name, s.account_label): s for s in session.execute(select(SyncState)).scalars().all()
    }

    all_pairs = set(tx_counts) | set(sync_by_account)

    result = []
    for source_name, account_label in sorted(all_pairs):
        sync_state = sync_by_account.get((source_name, account_label))
        result.append(
            {
                "source_name": source_name,
                "account_label": account_label,
                "transaction_count": tx_counts.get((source_name, account_label), 0),
                "last_synced_at": sync_state.last_synced_at if sync_state else None,
                "last_error": sync_state.last_error if sync_state else None,
                "is_configured": (source_name, account_label) in configured,
            }
        )
    return result


def delete_accounts(
    session: Session, pairs: list[tuple[str, str]], dry_run: bool = False
) -> list[dict]:
    """Delete Transaction/SyncState rows for exactly the given
    (source_name, account_label) pairs -- no notion of "still configured"
    here, unlike prune_stale_accounts below, which computes the pairs to
    pass in from what's no longer in .env. This is the primitive the
    Accounts page's explicit, user-chosen deletion uses directly.
    """
    reports = []
    for source_name, account_label in pairs:
        tx_count = session.execute(
            select(func.count())
            .select_from(Transaction)
            .where(
                Transaction.source_name == source_name,
                Transaction.account_label == account_label,
            )
        ).scalar_one()

        if not dry_run:
            session.execute(
                delete(Transaction).where(
                    Transaction.source_name == source_name,
                    Transaction.account_label == account_label,
                )
            )
            session.execute(
                delete(SyncState).where(
                    SyncState.source_name == source_name,
                    SyncState.account_label == account_label,
                )
            )

        reports.append(
            {
                "source_name": source_name,
                "account_label": account_label,
                "deleted_transactions": tx_count,
                "dry_run": dry_run,
            }
        )

    if not dry_run and pairs:
        session.commit()

    return reports


def prune_stale_accounts(
    session: Session, adapters: list[TransactionAdapter], dry_run: bool = False
) -> list[dict]:
    """Delete Transaction/SyncState rows for accounts that are no longer
    configured (i.e. not among `adapters`, which app.main builds fresh
    from the current .env on every request via build_adapters_from_config()).

    Matches on the (source_name, account_label) pair -- the same identity
    Transaction's unique constraint already uses -- not on the wallet
    address itself, so renaming a label is treated as removing the old
    account and adding a new one, while re-pointing a label at a different
    address keeps its existing history (address changes aren't detected;
    only removed labels are pruned).

    PriceCache rows are untouched: they're keyed by asset/date, not by
    account, and stay useful for any remaining account holding that asset.
    """
    configured = {(a.source_name, a.account_label) for a in adapters}

    existing = session.execute(
        select(Transaction.source_name, Transaction.account_label).distinct()
    ).all()
    stale = sorted({(row.source_name, row.account_label) for row in existing} - configured)

    return delete_accounts(session, stale, dry_run=dry_run)
```

**Note:** the previous version of `prune_stale_accounts` called `session.commit()` unconditionally when `not dry_run`; `delete_accounts` above only commits `if not dry_run and pairs` (avoids an unnecessary empty commit when there's nothing stale to delete — harmless either way, but cleaner).
```tsx
import { useEffect, useState } from "react";
import { fetchConfig, saveConfig } from "../api/client";
import type { ConfigField } from "../api/types";

function groupBySection(fields: ConfigField[]): Map<string, ConfigField[]> {
  const groups = new Map<string, ConfigField[]>();
  for (const field of fields) {
    const existing = groups.get(field.section) ?? [];
    existing.push(field);
    groups.set(field.section, existing);
  }
  return groups;
}

function Konfiguration() {
  const [fields, setFields] = useState<ConfigField[] | null>(null);
  const [values, setValues] = useState<Record<string, string>>({});
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [saved, setSaved] = useState(false);

  useEffect(() => {
    fetchConfig()
      .then((response) => {
        setFields(response.fields);
        const initial: Record<string, string> = {};
        for (const field of response.fields) {
          initial[field.name] = field.value;
        }
        setValues(initial);
      })
      .catch((err: unknown) => setError(err instanceof Error ? err.message : String(err)));
  }, []);

  async function handleSave() {
    setSaving(true);
    setError(null);
    setSaved(false);
    try {
      await saveConfig(values);
      setSaved(true);
    } catch (err: unknown) {
      setError(err instanceof Error ? err.message : String(err));
    } finally {
      setSaving(false);
    }
  }

  if (error && fields === null) {
    return (
      <div className="text-red-600">
        {error}. Läuft das Backend unter http://127.0.0.1:8000?
      </div>
    );
  }

  if (fields === null) {
    return <div>Konfiguration wird geladen…</div>;
  }

  const sections = groupBySection(fields);

  return (
    <div>
      <h2 className="mb-4 text-xl font-semibold">Konfiguration</h2>
      <p className="mb-6 text-sm text-gray-500">
        Änderungen werden sofort in der .env-Datei gespeichert und beim nächsten Sync verwendet - kein
        Neustart nötig. Secret-Felder zeigen nie den gespeicherten Wert - leer lassen, um ihn unverändert
        zu behalten.
      </p>

      {Array.from(sections.entries()).map(([section, sectionFields]) => (
        <fieldset key={section} className="mb-6 rounded border border-gray-200 p-4">
          <legend className="px-1 text-sm font-semibold">{section}</legend>
          <div className="space-y-3">
            {sectionFields.map((field) => (
              <div key={field.name}>
                <label htmlFor={field.name} className="mb-1 block text-sm text-gray-700">
                  {field.label}
                </label>
                <input
                  id={field.name}
                  type={field.is_secret ? "password" : "text"}
                  value={values[field.name] ?? ""}
                  placeholder={field.is_secret ? "•••• (unverändert lassen, um bestehenden Wert zu behalten)" : field.hint}
                  onChange={(e) => setValues((prev) => ({ ...prev, [field.name]: e.target.value }))}
                  className="w-full rounded border border-gray-300 px-3 py-2 text-sm"
                />
                {!field.is_secret && field.hint && (
                  <p className="mt-1 text-xs text-gray-400">{field.hint}</p>
                )}
              </div>
            ))}
          </div>
        </fieldset>
      ))}

      <button
        onClick={handleSave}
        disabled={saving}
        className="rounded bg-gray-900 px-4 py-2 text-sm text-white hover:bg-gray-700 disabled:opacity-50"
      >
        {saving ? "Speichert…" : "Speichern"}
      </button>

      {saved && <p className="mt-4 text-green-700">Gespeichert.</p>}
      {error && fields !== null && <p className="mt-4 text-red-600">{error}</p>}
    </div>
  );
}

export default Konfiguration;
```

```tsx
import { useEffect, useState } from "react";
import { deleteAccounts, fetchAccounts } from "../api/client";
import type { Account } from "../api/types";

function accountKey(account: { source_name: string; account_label: string }): string {
  return `${account.source_name}::${account.account_label}`;
}

function Accounts() {
  const [accounts, setAccounts] = useState<Account[] | null>(null);
  const [selected, setSelected] = useState<Set<string>>(new Set());
  const [error, setError] = useState<string | null>(null);
  const [deleting, setDeleting] = useState(false);

  function load() {
    fetchAccounts()
      .then((response) => setAccounts(response.accounts))
      .catch((err: unknown) => setError(err instanceof Error ? err.message : String(err)));
  }

  useEffect(load, []);

  function toggle(key: string) {
    setSelected((prev) => {
      const next = new Set(prev);
      if (next.has(key)) {
        next.delete(key);
      } else {
        next.add(key);
      }
      return next;
    });
  }

  async function handleDelete() {
    if (!accounts) return;
    const toDelete = accounts.filter((a) => selected.has(accountKey(a)));
    if (toDelete.length === 0) return;
    const confirmed = window.confirm(
      `${toDelete.length} Account(s) inkl. aller zugehörigen Transaktionen unwiderruflich löschen?`,
    );
    if (!confirmed) return;

    setDeleting(true);
    setError(null);
    try {
      await deleteAccounts(toDelete.map((a) => ({ source_name: a.source_name, account_label: a.account_label })));
      setSelected(new Set());
      load();
    } catch (err: unknown) {
      setError(err instanceof Error ? err.message : String(err));
    } finally {
      setDeleting(false);
    }
  }

  if (error && accounts === null) {
    return (
      <div className="text-red-600">
        {error}. Läuft das Backend unter http://127.0.0.1:8000?
      </div>
    );
  }

  if (accounts === null) {
    return <div>Accounts werden geladen…</div>;
  }

  return (
    <div>
      <h2 className="mb-4 text-xl font-semibold">Accounts</h2>
      <p className="mb-6 text-sm text-gray-500">
        Löscht Transaktionen und Sync-Status für ausgewählte Accounts unwiderruflich - unabhängig davon,
        ob sie noch in der .env konfiguriert sind.
      </p>

      <table className="mb-4 w-full text-left text-sm">
        <thead>
          <tr className="border-b border-gray-200">
            <th className="py-2"></th>
            <th className="py-2">Quelle</th>
            <th className="py-2">Account</th>
            <th className="py-2">Transaktionen</th>
            <th className="py-2">Konfiguriert</th>
            <th className="py-2">Letzter Fehler</th>
          </tr>
        </thead>
        <tbody>
          {accounts.map((account) => {
            const key = accountKey(account);
            return (
              <tr key={key} className="border-b border-gray-100">
                <td className="py-2">
                  <input type="checkbox" checked={selected.has(key)} onChange={() => toggle(key)} />
                </td>
                <td className="py-2">{account.source_name}</td>
                <td className="py-2">{account.account_label}</td>
                <td className="py-2">{account.transaction_count}</td>
                <td className="py-2">{account.is_configured ? "ja" : "nein"}</td>
                <td className="py-2 text-red-600">{account.last_error ?? ""}</td>
              </tr>
            );
          })}
        </tbody>
      </table>

      <button
        onClick={handleDelete}
        disabled={selected.size === 0 || deleting}
        className="rounded bg-red-700 px-4 py-2 text-sm text-white hover:bg-red-800 disabled:opacity-50"
      >
        {deleting ? "Löscht…" : "Ausgewählte löschen"}
      </button>

      {error && accounts !== null && <p className="mt-4 text-red-600">{error}</p>}
    </div>
  );
}

export default Accounts;
```
