# Plan 2b-2 – MEXC Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `MexcAdapter` that fetches successful deposits/withdrawals automatically and trades for manually-configured trading pairs, authenticated via MEXC's HMAC-SHA256 query-signing scheme, wired into the existing sync pipeline alongside Bitcoin/EVM/Kraken/Coinbase.

**Architecture:** A standalone HMAC-signing helper (`app/adapters/mexc_auth.py`) isolated from HTTP/adapter concerns, consumed by `MexcAdapter` (`app/adapters/mexc.py`), which follows the same `TransactionAdapter` interface as the sibling adapters. Deposits/withdrawals are asset-agnostic (no configuration needed); trades require the user to configure which trading pairs to track, since MEXC's trade-history endpoint requires an explicit `symbol` per call and cannot enumerate "all trades" the way Kraken's ledger endpoint can.

**Tech Stack:** Same as Phase 1/2a/2b-1 — Python, `requests`, `responses` for test mocking, pytest. No new dependencies (HMAC-SHA256 is stdlib `hmac`/`hashlib`, same as Kraken's adapter).

**Related docs:**
- [`docs/superpowers/specs/2026-08-03-phase2b2-mexc-design.md`](../specs/2026-08-03-phase2b2-mexc-design.md)
- [`docs/superpowers/plans/2026-07-30-backend-phase1.md`](2026-07-30-backend-phase1.md) (Phase 1, Kraken's HMAC pattern)
- [`docs/superpowers/plans/2026-08-02-phase2b1-coinbase.md`](2026-08-02-phase2b1-coinbase.md) (Plan 2b-1, auth-helper/adapter split pattern)

**Scope notes (decided during planning):**
- **Binance is a separate, later plan** (2b-3), per the user's "one exchange at a time" decision.
- **Trading pairs must be manually configured** (`MEXC_TRADING_PAIRS`), confirmed with the user, because MEXC's `GET /api/v3/myTrades` requires a mandatory `symbol` parameter — there is no "list all trades across all pairs" endpoint. Deposits/withdrawals need no such configuration.
- **MEXC's trade-history endpoint only returns the last 30 days**, regardless of `startTime`/`endTime` parameters (documented explicitly by MEXC: "Only the transaction records in the past 1 month can be queried"). This is a hard external limitation, not something this plan can code around. It must be documented prominently (Task 5) so the user understands they need to sync at least monthly to avoid gaps, and that older trade history requires a one-time manual CSV export from MEXC's website (outside this adapter's scope).
- **Trading pair symbols are configured with explicit base/quote assets** (`SYMBOL:BASE:QUOTE`, e.g. `BTCUSDT:BTC:USDT`) rather than parsed from the symbol string, since MEXC symbols concatenate base+quote with no separator and can't be reliably split without a known quote-currency list.
- **API research caveat:** MEXC's documented endpoint shapes (fields, status codes, pagination) were verified against `mexcdevelop.github.io/apidocs/spot_v3_en/` on 2026-08-03, but external API docs can drift. If shapes don't match reality by implementation time, treat the design's *intent* (HMAC-signed requests, status-code filtering, per-pair trade fetching) as authoritative and adjust field names/codes to match current docs — same caveat pattern already used in the Phase 1/2a/2b-1 plans for other external APIs.

```python
import hashlib
import hmac
import time
import urllib.parse


def sign_mexc_params(params: dict, secret: str) -> str:
    """Compute a MEXC Spot API v3 request signature: HMAC-SHA256 of the
    URL-encoded query string, keyed with the API secret, as lowercase
    hex - per MEXC's documented signing scheme."""
    query_string = urllib.parse.urlencode(params)
    return hmac.new(secret.encode(), query_string.encode(), hashlib.sha256).hexdigest()


def build_signed_params(params: dict, secret: str) -> dict:
    """Return a new params dict with a fresh millisecond timestamp and
    the computed signature attached, ready to send as a signed MEXC
    request's query parameters."""
    signed = dict(params)
    signed["timestamp"] = int(time.time() * 1000)
    signed["signature"] = sign_mexc_params(signed, secret)
    return signed
```

```python
import json
from datetime import datetime, timezone
from decimal import Decimal

import requests

from app.adapters.base import TransactionAdapter
from app.adapters.mexc_auth import build_signed_params
from app.schemas import NormalizedTransaction

API_URL = "https://api.mexc.com"
PAGE_LIMIT = 1000

DEPOSIT_SUCCESS_STATUSES = {"5", "12"}
WITHDRAWAL_SUCCESS_STATUS = "7"


class MexcAdapter(TransactionAdapter):
    source_type = "exchange"
    source_name = "mexc"

    def __init__(self, account_label: str, api_key: str, api_secret: str, trading_pairs: list):
        super().__init__(account_label)
        self.api_key = api_key
        self.api_secret = api_secret
        self.trading_pairs = trading_pairs

    def _get(self, path: str, params: dict) -> list:
        signed_params = build_signed_params(params, self.api_secret)
        response = requests.get(
            f"{API_URL}{path}",
            params=signed_params,
            headers={"X-MEXC-APIKEY": self.api_key},
            timeout=10,
        )
        response.raise_for_status()
        return response.json()

    def fetch_transactions(self, since: datetime | None) -> list[NormalizedTransaction]:
        results: list[NormalizedTransaction] = []
        results.extend(self._fetch_deposits(since))
        results.extend(self._fetch_withdrawals(since))
        return results

    def _fetch_all_records(self, path: str, since: datetime | None, time_field: str) -> list[dict]:
        all_records: list[dict] = []
        start_time_ms = int(since.timestamp() * 1000) if since is not None else None
        while True:
            params: dict = {"limit": PAGE_LIMIT}
            if start_time_ms is not None:
                params["startTime"] = start_time_ms
            batch = self._get(path, params)
            all_records.extend(batch)
            if len(batch) < PAGE_LIMIT:
                break
            start_time_ms = max(int(r[time_field]) for r in batch) + 1
        return all_records

    def _fetch_deposits(self, since: datetime | None) -> list[NormalizedTransaction]:
        results: list[NormalizedTransaction] = []
        for record in self._fetch_all_records("/api/v3/capital/deposit/hisrec", since, "insertTime"):
            if str(record.get("status")) not in DEPOSIT_SUCCESS_STATUSES:
                continue
            tx_id = record.get("txId")
            if not tx_id:
                continue
            timestamp = datetime.fromtimestamp(int(record["insertTime"]) / 1000, tz=timezone.utc)
            if since is not None and timestamp <= since:
                continue
            results.append(
                NormalizedTransaction(
                    timestamp=timestamp,
                    source_type=self.source_type,
                    source_name=self.source_name,
                    account_label=self.account_label,
                    tx_type="transfer_in",
                    asset=record["coin"],
                    amount=Decimal(str(record["amount"])),
                    external_id=f"deposit-{tx_id}",
                    raw_json=json.dumps(record),
                )
            )
        return results

    def _fetch_withdrawals(self, since: datetime | None) -> list[NormalizedTransaction]:
        results: list[NormalizedTransaction] = []
        for record in self._fetch_all_records("/api/v3/capital/withdraw/history", since, "applyTime"):
            if str(record.get("status")) != WITHDRAWAL_SUCCESS_STATUS:
                continue
            timestamp = datetime.fromtimestamp(int(record["applyTime"]) / 1000, tz=timezone.utc)
            if since is not None and timestamp <= since:
                continue
            fee_raw = record.get("transactionFee")
            fee_amount = Decimal(str(fee_raw)) if fee_raw and Decimal(str(fee_raw)) != 0 else None
            results.append(
                NormalizedTransaction(
                    timestamp=timestamp,
                    source_type=self.source_type,
                    source_name=self.source_name,
                    account_label=self.account_label,
                    tx_type="transfer_out",
                    asset=record["coin"],
                    amount=Decimal(str(record["amount"])),
                    fee_amount=fee_amount,
                    fee_asset=record["coin"] if fee_amount is not None else None,
                    external_id=f"withdrawal-{record['id']}",
                    raw_json=json.dumps(record),
                )
            )
        return results
```

```python
        results: list[NormalizedTransaction] = []
        for pair in self.trading_pairs:
            results.extend(self._fetch_trades_for_pair(pair, since))

    def _fetch_trades_for_pair(self, pair, since: datetime | None) -> list[NormalizedTransaction]:
        params: dict = {"symbol": pair.symbol, "limit": PAGE_LIMIT}
        if since is not None:
            params["startTime"] = int(since.timestamp() * 1000)
        records = self._get("/api/v3/myTrades", params)

        results = []
        for record in records:
            timestamp = datetime.fromtimestamp(int(record["time"]) / 1000, tz=timezone.utc)
            if since is not None and timestamp <= since:
                continue

            qty = Decimal(str(record["qty"]))
            quote_qty = Decimal(str(record["quoteQty"]))
            commission_raw = record.get("commission")
            commission = Decimal(str(commission_raw)) if commission_raw and Decimal(str(commission_raw)) != 0 else None
            commission_asset = record.get("commissionAsset") if commission is not None else None

            if record["isBuyer"]:
                asset, amount = pair.base_asset, qty
                counter_asset, counter_amount = pair.quote_asset, quote_qty
            else:
                asset, amount = pair.quote_asset, quote_qty
                counter_asset, counter_amount = pair.base_asset, qty

            results.append(
                NormalizedTransaction(
                    timestamp=timestamp,
                    source_type=self.source_type,
                    source_name=self.source_name,
                    account_label=self.account_label,
                    tx_type="swap",
                    asset=asset,
                    amount=amount,
                    counter_asset=counter_asset,
                    counter_amount=counter_amount,
                    fee_amount=commission,
                    fee_asset=commission_asset,
                    external_id=f"trade-{pair.symbol}-{record['id']}",
                    raw_json=json.dumps(record),
                )
            )
        return results
```

```python
def parse_trading_pairs(env_value: str | None) -> list[TradingPairConfig]:
    if not env_value:
        return []
    pairs = []
    for entry in env_value.split(","):
        parts = entry.split(":")
        if len(parts) != 3:
            continue
        symbol, base_asset, quote_asset = (p.strip() for p in parts)
        if symbol and base_asset and quote_asset:
            pairs.append(TradingPairConfig(symbol=symbol, base_asset=base_asset, quote_asset=quote_asset))
    return pairs
```
